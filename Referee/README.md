# Referee

Referee remembers *what you agreed*. 

A conversational agent powered by the Model Context Protocol (MCP) that parses vague money-handshake deals, asks clarifying questions to lock down exact terms, and provides a neutral verdict on payments and deadlines.

## Features
- Simulated Alexa+ experience.
- No legal advice or payment verification is provided; this is a neutral record of what users state.
- Developed for the Amazon Developer Hackathon 2026.
